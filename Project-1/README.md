To-Do List – Python Project
A simple and interactive To-Do List application developed using Python.
This project allows users to add and view their daily tasks through a menu-driven interface.
It uses Python lists to store tasks temporarily and demonstrates fundamental programming concepts such as
-> Functions
-> Loops
-> Conditional statements  
-> User input
-> Task management
The project is designed to strengthen problem-solving skills and provide practical experience in developing beginner-friendly Python applications.
